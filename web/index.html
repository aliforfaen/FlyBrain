The brain runs hard when the house is interesting and idles when it is not. What it may touch —

Jev judgment layer off — nothing is sent
Jev is an optional outside service that classifies a decision. Jevless mode is the default: the brain, the colour and this dashboard run exactly as they do with Jev on — Jev is never in the render path — but no request leaves this machine and nothing is spent, so the decision inspector cannot explain a decision. Turning it on sends one decision's state (temperature, chosen and ideal colour, spike counts, busiest regions) to TypeSafe and costs roughly $0.0002 each.

How often it decides —
The brain steps as fast as the GPU allows, then waits this long before deciding again. 0 runs flat out (~165 W); 15 s averages ~40 W, and a room does not change faster than that. This is the setting that decides what it costs to leave running.
Looking for something to happen
Reading a sensor costs no GPU time, so between decisions the loop can watch the house cheaply. When the thermometer moves further than this, or a motion sensor changes state, it runs at full rate for the burst — capturing the event rather than sampling it once. The heartbeat above still guarantees a decision either way, which is what keeps the quiet windows coming. 0 turns the trigger off.
Smoothing s
Averaging time on the sensor. Real sensors jitter; this stops the light twitching. 0 turns it off.
Ignore changes under K
Stops the light being re-sent for changes you could not see. The chart still shows every decision.
